# myDash

Self-hosted Minecraft server management dashboard with a shared API and multi-loader support.

## Initial targets

- NeoForge 1.21.1
- Fabric 1.21.1
- Shared core/API
- Embedded web dashboard
- Future targets: Forge, NeoForge, Fabric, Paper across supported Minecraft versions

## Artifact naming

`myDash-{platform}-{minecraftVersion}-v{myDashVersion}.jar`

Example:

`myDash-neoforge-1.21.1-v2.1.0.jar`
